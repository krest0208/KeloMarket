# KELO WOOD MARKET

Интернет-магазин слэбов карельской сосны Кело. Чёрный фон, бледный древесно-жёлтый акцент, крупная современная типографика и фотографии натурального дерева. React 19, Vinext, Cloudflare Workers, D1 и R2.

## Что работает

Главная страница, каталог шести категорий, поиск, фильтры, избранное, карточки изделий, конструктор длины и обработки, корзина на устройстве, оформление заказа, сохранение заказов в D1, панель управления, загрузка фотографий в R2, цены обработки, статусы, резервирование и возврат доступной длины.

Данные каталога заполняются демонстрационными товарами при первом обращении. На страницах явно отмечено, что цены и сгенерированные изображения — примеры. Все цены вычисляются сервером при оформлении. Заказ сохраняется атомарно с резервом материала; повторный запрос не списывает остаток повторно. При отмене материал возвращается ровно один раз. Пропил и выбор участка доски пока не учитываются.

## Доступ

Сайт опубликован с доступом только владельцу. Панель `/admin` и её API опираются на эту границу доступа и проверяют серверный заголовок аутентификации. При переводе сайта в публичный режим обязательно сначала добавить отдельную авторизацию администратора по allowlist user ID / ролям; одной аутентификации посетителя для этого недостаточно. В локальном режиме DEV панель доступна для проверки.

## Интеграции и запуск продаж

ЮKassa и Яндекс Доставка не подключены. Форма не собирает банковские данные и не списывает деньги. Стоимость доставки до 250 см — демонстрационная формула; для длинных досок требуется индивидуальное согласование. Реальная отправка и уведомления менеджеру не выполняются.

Перед приёмом настоящих заказов нужны: реальные фотографии и складские размеры, юридические реквизиты, контакты, политика данных и оферта, merchant-аккаунт ЮKassa, ключи и webhook платежей с проверкой подписи, договор и API Яндекс Доставки, правила упаковки и производства, роли администратора. Секреты должны задаваться через runtime environment Sites, не в исходниках.

## Разработка и проверки

- Установка и сборка — через helpers Sites.
- `node node_modules/typescript/bin/tsc --noEmit` — проверка типов.
- `node --import ./node_modules/.pnpm/tsx@4.22.1/node_modules/tsx/dist/loader.mjs --test tests/commerce.test.ts` — цены, длинномер, атомарный резерв, повтор запроса и возврат материала.
- Схема — `db/schema.ts`, миграции — `drizzle/`.
- Настройки размещения — `.openai/hosting.json`.
- Изображения — `public/images`, локальные шрифты — `public/fonts`.

Домен бренда: kelowoodmarket.ru. DNS проверяется отдельно от публикации на служебном адресе.

## GitHub и последующие изменения

Исходники проекта: https://github.com/krest0208/KeloMarket, ветка `main`. После каждого завершённого изменения в этом проекте нужно обновлять сайт и отправлять проверенный исходный код в этот репозиторий. Правило закреплено в `AGENTS.md`, настройки — в `.openai/github.json`.

`node scripts/prepare-github-sync.mjs manifest` подготавливает список файлов точного коммита и проверяет его на случайно добавленные секреты. Команда `batch N` выдаёт содержимое для загрузки через подключённый GitHub. Файлы среды, база заказов и содержимое хранилища пользователей в исходники не включаются.

Сейчас используются две вкладки заказа: доски длиной 30–150 мм и товары с размерами из каталога. Количество учитывается в цене и остатке; комплект менсолодержателей и подарочная упаковка стоят по 300 ₽ за изделие. 3D-просмотр отключён.
